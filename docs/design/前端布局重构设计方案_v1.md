# 灵犀同传 LingoSync · 前端布局重构设计方案 v1

> 日期：2026-06-05 ｜ 状态：**设计稿（暂不落地，待工作区交接后实现）**
> 美学方向（用户已选）：**高端编辑 · 浅亮主屏 + 深色工作台**
> 设计依据 skill：`frontend-design`（官方）/ `high-end-visual-design`（soft）/ `minimalist-ui` / `frontend-design-direction` / `design-system`；动效 `gsap-*`
> 核心原则（来自官方 frontend-design）：**拒绝通用 AI 套路**——不用 Inter/Roboto、不用紫渐变白底、不用呆板对称；选定一个明确美学方向并精确执行。

---

## 0. 一句话目标

把当前"功能堆叠"的前端，重构成**两级清晰动线**：
**主屏（选 Web / 客户端）→ 设置弹窗（中间态）→ 沉浸式同传工作台**，
工作台左视频右字幕，字幕支持「分区对照」与「逐句对照」两种模式，并把"实时自动纠偏"做成可见的动效亮点。

## 1. 设计基调（Design Tokens）

> 全部以 CSS 变量 + Tailwind theme extend 落地，浅/深两套语义色。

### 1.1 字体（避开 Inter/Roboto）
| 用途 | 西文 | 中文 |
|---|---|---|
| Display 标题 | **Fraunces**（高对比衬线，有编辑气质） | **思源宋体 Source Han Serif** |
| 正文 / UI | **Satoshi** 或 **Geist Sans** | **HarmonyOS Sans / 思源黑体** |
| 数字 / 计时 / 技术标签 | **Geist Mono / JetBrains Mono** | 同左 |

字体策略：标题用衬线制造"大气、编辑感"，正文无衬线保证字幕可读性；中英混排时统一行高与基线。

### 1.2 配色

**浅色（主屏 / 设置弹窗）— 暖白编辑风**
```
--bg        #FAF8F3   暖白纸底
--surface   #FFFFFF   卡片面
--ink       #17212B   主文字（近黑墨）
--ink-soft  #5B6470   次要文字
--line      #E6E2D8   细分隔线（暖灰）
--brand     #2F5D50   品牌墨绿（沉稳）
--accent    #C8884A   琥珀（强调/CTA）
```
**深色（工作台）— 专注护眼**
```
--bg        #14161A   近黑底
--surface   #1C1F26   面板
--src       #C9CDD4   源文（冷灰白，弱）
--dst       #FFFFFF   译文（纯白，强）
--accent    #E0A458   琥珀高亮（"正在生成"）
--ok        #5FB48A   已确认/已纠偏完成
--warn      #E0A458   纠偏中
--muted     #6B7280   时间/元信息
```
> 选墨绿+琥珀而非蓝紫，刻意避开"AI 套路色"。深色用暖琥珀做高亮，长时间盯字幕不刺眼。

### 1.3 形状 / 阴影 / 间距
- 圆角：卡片 16px ／ 字幕句对卡 12px ／ 按钮 10px ／ 输入 8px
- 阴影（浅色，多层细腻）：`0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.06)`
- 间距：8pt 栅格；主屏大留白（区块间距 64–96px），工作台紧凑（16–24px）
- 描边：浅色 1px `--line`；深色高亮句对用 1.5px `--accent` + 外发光

### 1.4 动效原则（GSAP）
- **高影响时刻优先**：主屏一次性 stagger 入场 > 到处碎微交互
- 字幕进入：`fade + y:8→0`，120–180ms，`power2.out`
- "正在生成"卡：琥珀描边 **呼吸**（opacity/scale 微脉冲，循环）
- **纠偏动效（产品亮点）**：历史句被纠正时 → 旧文 `strike + fade out` → 新文 `fade in + 短暂高亮闪烁`
- 模式切换（分区⇄逐句）：用 **GSAP Flip** 做布局形变过渡，不闪
- 全部走 `gsap-frameworks` 的 Vue 规范：`onMounted` 创建、`onUnmounted` `ctx.revert()` 清理，选择器用 scope

**要点**

## 4. Web 工作台（深色 · 沉浸）

占满整屏，左右分栏（默认 52% / 48%，分隔条可拖拽）。

```
┌───────────────────────────┬────────────────────────────────┐
│  ‹ 返回   会话名 · EN→中     │  〔 分区对照 〕  〔 逐句对照 〕  │ ← 顶栏+模式切换(segmented)
│  ● listening  00:42         ├────────────────────────────────┤
│                             │                                │
│   ┌─────────────────────┐   │   （右栏随模式切换，见 4.1/4.2）│
│   │                     │   │                                │
│   │      ▶  视频         │   │                                │
│   │                     │   │                                │
│   └─────────────────────┘   │                                │
│   ▮▮▮▮▮▮▯▯▯▯  -02:18         │                                │
│   ◁◁  ⏸  ▷▷   🔊──●──        │                                │
│                             │                                │
│   [⚙ 设置]  [⛶ 悬浮]  [■ 结束]│                                │
└───────────────────────────┴────────────────────────────────┘
```
左栏 = `MediaPanel.vue`：视频/音频播放（纯音频时显示波形/封面）、进度、音量、播放控制、底部操作（设置 / 唤起悬浮窗 / 结束）。
顶部状态点复用 `sourceSyncState`（listening/syncing/lagging/missing/recovered）做颜色+文案。

### 4.1 分区对照模式（上源 / 下译）
```
右栏纵向分两区（上 42% 源 / 下 58% 译，分隔可调）：
┌────────────────────────────┐
│ 源文 EN              ⠿ 实时  │  ← 区头(sticky)
│ ...........................  │
│ ...........................  │  ← 源语言流，新句底部追加，自动吸底
│ 当前识别中 ▍                 │  ← 光标式 partial
├────────────────────────────┤
│ 译文 中              ⠿       │
│ ...........................  │
│ ...........................  │  ← 中文译文流
│ 正在翻译…                    │
└────────────────────────────┘
```
- 上下两区**时间轴对齐**：hover 源句 → 对应译句高亮（共用 segmentId）。
- 各自独立滚动，默认吸底；用户上滚查看历史时停止吸底并显示"↓ 回到最新"。

### 4.2 逐句对照模式（上下合并为句对卡片流）
```
┌──────────────────────────────────┐
│ ┌──────────────────────────────┐ │
│ │ EN  Good morning everyone.    │ │ ← 已完成句对(静态卡, --surface)
│ │ 中  大家早上好。               │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ EN  Today we'll talk about…   │ │ ← 已完成
│ │ 中  今天我们来聊聊……           │ │
│ └──────────────────────────────┘ │
│ ╔══════════════════════════════╗ │
│ ║ EN  The key idea is ▍         ║ │ ← 正在生成(琥珀描边+呼吸)
│ ║ 中  核心思路是……(逐词浮现)     ║ │
│ ╚══════════════════════════════╝ │
└──────────────────────────────────┘
```
- 一卡 = 一个句段（源文上、译文下，12px 圆角）。已完成卡静态；当前卡 `--accent` 描边 + 呼吸动效 + 译文逐词浮现。
- **自动纠偏可视化**：历史卡被纠正时，命中文字 `strike→fade`，新文 `fade in + 高亮闪一下`，卡片右上角浮现小标 `↺ 已校正`（2s 后淡出）。这是选题二的差异化亮点，必须做得明显。
- 新卡从底部 `y:12→0 + fade` 入场；列表吸底逻辑同 4.1。

**右栏组件**：`SubtitleColumn.vue`（容器+模式切换+吸底逻辑）→ `SplitParallelView.vue` / `SentencePairView.vue` → `SentencePairCard.vue`、`StreamLine.vue`；`ModeSwitch.vue`（segmented）。
模式切换用 **GSAP Flip** 过渡。
